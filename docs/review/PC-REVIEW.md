## Windows unit test run

`python -m unittest discover -s tests` on Windows: 992 tests, 54-61 s, **16 not passing** (14 errors, 2 failures). None is a defect of the tools (checks 1-15 exercise the same code on real data); all are test code or test doubles written on Linux.

```
ID: R6-001
WHERE: tests/support.py:165-167 (FakeCar.key), tests/test_tune_engine.py:1419-1424 (TestApply.rename), 1451-1452 (built)
CATEGORY: test
SEVERITY: medium
CONFIDENCE: verified
EVIDENCE: 12 tests of TestApply error with KeyError on `...\build\ax_x\content\cars\ax_x\data\x.car`; `os.path.realpath('\\?\C:\nonexist\a\b')` keeps the `\\?\` prefix on Windows 3.12.
PROBLEM: tune.apply renames with kspkg.long_path(...) paths, which on Windows always start with `\\?\`. The test double for os.rename keys its in-memory store with realpath, so the keys of the files below the `.partial` folder are looked up with the prefix but were stored without it; the renamed files are not found.
FIX: FakeCar.key should strip the extended-length prefix (kspkg.plain_path) before realpath; then run the 12 tests: test_a_changed_tyre_value..., test_a_changed_value_is_written..., test_a_choice_setting..., test_a_flag_with_a_non_zero_value..., test_a_missing_last_field..., test_both_axles..., test_create_missing..., test_curve_scale..., test_flag_wins..., test_flag_writes_its_value..., test_floats_are_written..., test_the_shared_tyre_file....
```

```
ID: R6-005
WHERE: tests/test_tuner_server.py:376-378 (TestHostAndHeaders.test_the_post_headers_are_checked_before_the_route); tools/tuner_server.py (403 on a POST without X-Tuner)

SEVERITY: low
CONFIDENCE: verified
EVIDENCE: ConnectionAbortedError [WinError 10053] in the test client when the POST without X-Tuner is answered with 403 and the connection is closed. Raw requests from PowerShell (small body) get the 403 text correctly.
```
