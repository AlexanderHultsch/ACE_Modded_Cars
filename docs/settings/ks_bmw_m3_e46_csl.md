# BMW M3 E46 CSL: tuner settings

This file lists the tuner settings (`tuner/catalogue.json`) of the BMW M3 E46 CSL (car id `ks_bmw_m3_e46_csl`) with their defaults. It is generated by `python tools/tune.py doc --car ks_bmw_m3_e46_csl`, do not edit it by hand. The defaults are read from the stock car in the game. Applicable settings only: settings this car does not have are hidden. "unverified" means the meaning is guessed from the field name and not confirmed in the game. The settings of the group Display change only text. The setup limits (the settings ending in _min or _max) are not yet tested in the game.

## Engine

| Variable | Name | Default | Unit | Description | Status |

| `idle_rpm` | Idle rpm | 700 | rpm | Minimum is the stall rpm of the engine (EngineData.minimum), the lowest engine speed. Whether it also sets the idle speed is not confirmed in the game. | unverified |
