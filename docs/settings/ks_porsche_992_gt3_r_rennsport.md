# Porsche 911 GT3 R Rennsport (992): tuner settings

This file lists the tuner settings (`tuner/catalogue.json`) of the Porsche 911 GT3 R Rennsport (992) (car id `ks_porsche_992_gt3_r_rennsport`) with their defaults. It is generated by `python tools/tune.py doc --car ks_porsche_992_gt3_r_rennsport`, do not edit it by hand. The defaults are read from the stock car in the game. Applicable settings only: settings this car does not have are hidden. "unverified" means the meaning is guessed from the field name and not confirmed in the game. The display values change only text. Setting limits is not yet tested in the game.
